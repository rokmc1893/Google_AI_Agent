# 담당 역할과 주요 작업

Deepgle Legal의 데이터 수집·정리와 프론트엔드·백엔드 개발에 참여했다. 계약서 업로드부터 분석·결과 조회까지 연결하고 팀원의 API·검색 변경을 통합했다.

## 주요 작업

| 영역 | 수행 내용 | 관련 코드·문서 |
|---|---|---|
| 분석 서비스·API | FastAPI의 업로드·스크리닝·결과 조회, Gemini 호출과 실패 시 폴백을 서비스 흐름으로 연결했다. | [backend/agent_graph.py](../backend/agent_graph.py) |
| 법령 근거 연동 | 법령 검색·로컬 DB 폴백과 RAG를 분석 파이프라인에 연결하고 팀원의 검색·법령 처리 변경을 통합했다. | [backend/rag](../backend/rag) |
| 프론트엔드 | 파일 업로드·분석 요청·결과 조회 API와 대시보드·마스킹 비교 화면을 연결하고 한국어 안내·데모 흐름을 보완했다. | [src/api/client.ts](../src/api/client.ts) |
| 통합·검증 | 팀원 API·모듈 변경을 병합하고 마스킹·테스트 폴백과 프론트 빌드/백엔드 테스트 수집 CI를 정리했다. | [tests/test_masking.py](../tests/test_masking.py) |

## 개발 범위

팀 프로젝트로 진행했으며 법령 데이터·검색·API·화면 구현을 팀원들과 통합했다.
