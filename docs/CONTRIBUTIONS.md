# 유소민의 역할과 기여

유소민은 Deepgle Legal 팀 프로젝트에서 데이터 수집·정리와 프론트엔드·백엔드 개발에 참여하고, 계약서 업로드부터 분석·결과 조회까지의 API 연결과 데모 흐름 통합을 진행했다.

2026-11-11 기준으로 기존 역할 소개, 저장소 파일·커밋과 관련 Codex 채팅을 대조했다. 개발·조사·문서화에는 Codex·Claude 등 AI 도구를 활용했으며, 팀 공동 작업과 본인의 담당 범위를 구분했다.

- **기존 프로필의 담당 경험:** 데이터 수집·API·프론트엔드·백엔드 담당 범위를 확인했다.
- **yusomin 커밋 04137f5:** FastAPI Phase 1~7, 프론트 API 연결, RAG·LangGraph·Docker 관련 파일이 반영된 작업 이력이다.
- **yusomin 커밋 a76ce4c·c9e208b·f5bc012·e265cfe·531a8e1:** 팀원 변경 통합, 마스킹·pytest 폴백, 데모 안정화와 UI 개선 이력이다.

## 검증 범위와 협업

팀원의 API·법령 데이터·검색·화면 구현과 공동으로 만든 결과다. 전체 시스템을 단독 개발한 것으로 표시하지 않는다. README에 남아 있는 핵심 테스트 130건 통과·1건 실패, 린트 실패와 CI의 collect-only 한계를 유지한다. 테스트 수집 성공은 테스트 실행이나 실제 LLM·DB 연동 성공과 다르다.

이번 변경은 역할 문서 정리다. 앱 테스트·실계정 연동·배포·대회 제출을 새로 수행한 결과로 표시하지 않는다. 채팅 원문과 계정 비밀값은 저장소에 옮기지 않았다.
